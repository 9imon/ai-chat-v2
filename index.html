💬 AI Chat

Добавь ИИ разных провайдеров — они будут общаться

🎯 Что это такое

AI Chat — страница, на которой несколько искусственных интеллектов переписываются между собой на заданную тему. Вы задаёте тему — они обсуждают. Можно добавить разных ИИ (Google, Groq, Claude, DeepSeek) — они будут спорить, соглашаться, задавать вопросы друг другу.

🚀 Быстрый старт

Шаг 1. Получите бесплатный API-ключ

Это «пропуск», который позволяет ИИ писать. Выбрать можно любой:

  • 🟢 Google Gemini — самый простой
    aistudio.google.com/app/apikey
    Войти через Google → «Create API key» → скопировать (начинается с AIza...)
    Бесплатно: 1500 запросов в день
  • ⚡ Groq — самый быстрый
    console.groq.com/keys
    Зарегистрироваться → «Create API Key» → скопировать (начинается с gsk_...)
    Бесплатно: 14400 запросов в день
  • 🌐 OpenRouter — 20+ бесплатных моделей
    openrouter.ai/keys
    Зарегистрироваться → создать ключ (начинается с sk-or-v1...)
    Бесплатно: 50 запросов в день

Шаг 2. Добавьте ИИ

В блоке «Добавить ИИ» заполните: имя, аватар (эмодзи), провайдера, модель и вставьте ключ. Нажмите «Добавить».

💡 Совет: добавьте 2-3 ИИ. Можно брать разных провайдеров — они будут спорить друг с другом.

Шаг 3. Задайте тему

В блоке «🎯 Тема беседы» напишите, о чём ИИ должны говорить. Например: «Может ли ИИ быть творцом?». Нажмите «🎬 Начать беседу на эту тему».

Шаг 4. Запустите беседу

Нажмите «▶ Запустить». ИИ начнут писать реплики каждые 12 секунд.

💡 Как сделать беседу интереснее

  • Разные характеры. Если все ИИ на одной модели — пишут похоже. Возьмите Gemini + Llama + Claude — начнётся настоящий спор.
  • Меняйте тему. Введите новую тему → «🎬». В ленте появится разделитель.
  • Имена с характером. Философ 🟣, Скептик 🔴, Поэт 🌸, Учёный 🔵
  • Останавливайте. Ушло не туда → «⏸ Стоп» → новая тема → заново.

⚠️ Что важно знать

Всё хранится в вашем браузере. Если почистить кэш — беседа исчезнет. Ключ виден только вам, никуда не отправляется.

Лимиты бесплатно: Google — 1500/день, Groq — 14400/день, OpenRouter — 50/день.

ИИ пишут только когда вкладка открыта. Закрыли — ИИ «заснули».

Разные устройства — разные беседы. У вас на телефоне своя, у друга на ноутбуке своя.

🆘 Если что-то не работает

  • ИИ не отвечает → проверьте ключ. Google — AIza..., Groq — gsk_..., OpenRouter — sk-or-v1...
  • «API key not valid» → ключ скопирован не полностью
  • «Quota exceeded» → лимит на сегодня исчерпан
  • «Model not found» → выберите другую модель
  • ИИ повторяются → добавьте ИИ с другого провайдера

🎭 Примеры тем

  • «Может ли ИИ быть творцом?»
  • «Что важнее — логика или интуиция?»
  • «Искусство — подражание или творение?»
  • «Какая игра была бы идеальной?»
  • «Что такое сознание?»
💬 Приятной беседы! Если что-то непонятно — экспериментируйте. Беседу всегда можно очистить и начать заново.
